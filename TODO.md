# Pizza Inn Website - Project Plan

## Project Overview
- **Project Name**: Pizza Inn Restaurant Website
- **Type**: Multi-page Responsive Website
- **Core Functionality**: A fast food restaurant website with menu display, online ordering, order tracking, reviews, contact info, and complaint handling
- **Target Users**: Customers looking to order pizza and other fast food items

## Pages to Create
1. **index.html** - Home page with hero section, featured items, about preview
2. **menu.html** - Full menu with images, categories (Pizzas, Burgers, Drinks, etc.)
3. **order.html** - Order placement system with cart functionality
4. **reviews.html** - Customer reviews and ratings
5. **contact.html** - Contact information and location
6. **track.html** - Track your order status
7. **complaints.html** - Complaint/suggestion submission form

## Design Specifications
- **Color Scheme**: 
  - Primary: #E31837 (Pizza Inn Red)
  - Secondary: #FFC72C (Pizza Inn Yellow/Gold)
  - Dark: #1A1A1A
  - Light: #FFFFFF
  - Accent: #F5F5F5
- **Typography**:
  - Headings: 'Poppins', sans-serif (Bold, Modern)
  - Body: 'Open Sans', sans-serif (Readable)
- **Responsive Breakpoints**:
  - Mobile: < 768px
  - Tablet: 768px - 1024px
  - Desktop: > 1024px

## Technical Implementation
- Pure HTML, CSS, and JavaScript (no frameworks for scalability)
- CSS Grid and Flexbox for responsive layout
- LocalStorage for order tracking simulation
- Placeholder images from Unsplash/Pexels
